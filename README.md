\# Calculadora



Calculadora de consola escrita en Python. Permite sumar, restar, multiplicar y dividir dos números.



\## Requisitos



\- Python 3.8 o superior



\## Ejecución



```bash

python calculadora.py

```



El programa pide dos números y la operación (`+`, `-`, `\*` o `/`) y muestra el resultado.



\## Ejemplo



```text

=== Calculadora ===

Operaciones disponibles: +  -  \*  /

Primer número: 6

Segundo número: 3

Operación: \*

Resultado: 18.0

```



\## Cómo colaborar



Este proyecto se desarrolla en equipo siguiendo Gitflow:



\- La rama `main` contiene la versión estable y `develop` la de desarrollo.

\- Cada tarea se hace en una rama propia (`feature/...` o `bugfix/...`) a partir de `develop`.

\- Cada cambio debe tener una Issue asociada y entrar mediante un Pull Request, revisado por otro compañero.
