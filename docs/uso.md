# Guía de uso

## Requisitos

- Python 3.8 o superior

Comprueba la versión con:

```bash
python --version
```

## Ejecución

Desde la carpeta del proyecto:

```bash
python calculadora.py
```

El programa pide dos números y la operación, y muestra el resultado.

## Operaciones disponibles

| Símbolo | Operación |
|---|---|
| `+` | Suma |
| `-` | Resta |
| `*` | Multiplicación |
| `/` | División |

## Ejemplo de ejecución

```text
=== Calculadora ===
Operaciones disponibles: +  -  *  /
Primer número: 5
Segundo número: 3
Operación: -
Resultado: 2.0
```

## Errores conocidos

Los errores detectados se registran como Issues en GitHub, con la plantilla
**Informe de error**.
